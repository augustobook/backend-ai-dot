# 🐍 Chatbot de Python DOT Group

Este é um assistente de IA que responde **perguntas sobre programação em Python**.
Ele foi construído com [LangChain](https://python.langchain.com/) e um modelo da família GPT-4 da OpenAI.

## O que ele faz

- Explica conceitos de Python passo a passo, do básico ao avançado.
- Mostra exemplos de código comentados, armadilhas comuns e boas práticas.
- Lembra da conversa, então você pode fazer perguntas de acompanhamento
  (por exemplo: *"Como criar uma lista?"* → *"E como adiciono um item nela?"*).
- Responde no **mesmo idioma** em que você escrever.

## Limites

- Ele só fala sobre **Python**. Outros assuntos são recusados educadamente.
- As respostas são geradas por um modelo de IA e podem conter erros: teste o código
  antes de confiar nele.
- As conversas ficam **salvas** e aparecem na lista lateral: você pode reabrir uma
  conversa e continuar de onde parou. Clicar em **Novo chat** começa uma conversa
  nova, sem apagar as anteriores.
- O chat é aberto, sem login: a lista de conversas é **compartilhada** por todos que
  usam este chat.
- Cada pergunta pode ter até **5000 caracteres**, e cada conversa tem um tamanho
  máximo. Perto do limite você recebe um aviso; ao atingi-lo, basta clicar em
  **Novo chat**.
- Não compartilhe senhas, chaves de API ou outros dados sensíveis no chat: as
  conversas ficam visíveis para outros usuários.

Escolha uma das perguntas sugeridas ou digite a sua para começar!
