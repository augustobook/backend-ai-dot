## 1. Lists and a follow-up question

> The second question only makes sense with the context of the first (memory).

### 🧑 Como criar uma lista em Python?

**Conceito**: Em Python, uma lista é uma coleção ordenada e mutável de itens. Você pode criar uma lista usando colchetes `[]` e separando os elementos por vírgulas.

**Exemplo**: Aqui está um exemplo simples de como criar uma lista e imprimir seus elementos.

```python
# Criando uma lista com alguns números
numeros = [1, 2, 3, 4, 5]

# Imprimindo a lista
print(numeros)  # Saída: [1, 2, 3, 4, 5]

# Acessando um elemento da lista (o primeiro elemento)
print(numeros[0])  # Saída: 1
```

**Erros comuns**: Um erro comum é tentar acessar um índice que não existe na lista, o que resultará em um `IndexError`. Por exemplo, se você tentar acessar `numeros[5]` em uma lista com apenas 5 elementos (índices de 0 a 4), ocorrerá um erro.

**Melhores práticas**: Ao criar listas, é uma boa prática usar nomes de variáveis descritivos que indiquem o que a lista contém, como `numeros`, `nomes`, ou `itens`.

### 🧑 E como adiciono e removo itens dessa lista?

**Conceito**: Você pode adicionar e remover itens de uma lista em Python usando métodos embutidos. Os métodos mais comuns para adicionar itens são `append()` e `insert()`, enquanto para remover itens, você pode usar `remove()` e `pop()`.

**Exemplo**: Abaixo estão exemplos de como adicionar e remover itens de uma lista.

```python
# Criando uma lista inicial
frutas = ['maçã', 'banana', 'laranja']

# Adicionando um item ao final da lista
frutas.append('uva')
print(frutas)  # Saída: ['maçã', 'banana', 'laranja', 'uva']

# Adicionando um item em uma posição específica (índice 1)
frutas.insert(1, 'manga')
print(frutas)  # Saída: ['maçã', 'manga', 'banana', 'laranja', 'uva']

# Removendo um item pelo valor
frutas.remove('banana')
print(frutas)  # Saída: ['maçã', 'manga', 'laranja', 'uva']

# Removendo um item pelo índice (último item)
ultima_fruta = frutas.pop()  # Remove e retorna o último item
print(ultima_fruta)  # Saída: 'uva'
print(frutas)  # Saída: ['maçã', 'manga', 'laranja']
```

**Erros comuns**: Um erro comum ao usar `remove()` é tentar remover um item que não está na lista, o que resultará em um `ValueError`. Já ao usar `pop()` com um índice que não existe, você receberá um `IndexError`.

**Melhores práticas**: Ao adicionar ou remover itens, sempre verifique se o item existe na lista antes de removê-lo, para evitar erros. Além disso, prefira `append()` para adicionar itens ao final da lista, pois é mais eficiente.

## 2. List vs. tuple

> Conceptual comparison.

### 🧑 Qual a diferença entre lista e tupla?

A diferença entre listas e tuplas em Python está principalmente em sua mutabilidade e uso. Vamos explorar esses conceitos:

#### Conceito

- **Lista**: É uma coleção ordenada e mutável de elementos. Isso significa que você pode modificar, adicionar ou remover elementos após a criação da lista.
  
- **Tupla**: É uma coleção ordenada e imutável de elementos. Uma vez que uma tupla é criada, você não pode alterar seus elementos, adicionar novos ou remover existentes.

#### Exemplos

Aqui estão alguns exemplos que ilustram as diferenças:

```python
# Exemplo de lista
lista = [1, 2, 3]
print("Lista original:", lista)

# Modificando a lista
lista.append(4)  # Adicionando um elemento
print("Lista após adicionar um elemento:", lista)

# Removendo um elemento
lista.remove(2)
print("Lista após remover um elemento:", lista)

# Exemplo de tupla
tupla = (1, 2, 3)
print("Tupla original:", tupla)

# Tentando modificar a tupla (isso causará um erro)
# tupla[0] = 10  # Isso geraria um TypeError
```

##### Saída Esperada:
```
Lista original: [1, 2, 3]
Lista após adicionar um elemento: [1, 2, 3, 4]
Lista após remover um elemento: [1, 3, 4]
Tupla original: (1, 2, 3)
```

#### Armadilhas Comuns

1. **Tentativa de Modificação**: Um erro comum é tentar modificar uma tupla, o que resultará em um `TypeError`.
2. **Uso de Listas para Dados Imutáveis**: Às vezes, as pessoas usam listas quando deveriam usar tuplas, especialmente quando os dados não devem ser alterados.

#### Melhores Práticas

- Use **listas** quando você precisa de uma coleção de itens que pode mudar ao longo do tempo.
- Use **tuplas** quando você deseja garantir que os dados não sejam alterados, ou quando você precisa de uma coleção que será usada como chave em um dicionário (já que tuplas são hashable, enquanto listas não são).

Essas são as principais diferenças entre listas e tuplas em Python! Se você tiver mais perguntas ou precisar de mais detalhes, fique à vontade para perguntar.

## 3. List comprehensions

> Concept with several code examples.

### 🧑 O que são list comprehensions? Dê exemplos.

**Conceito**:  
List comprehensions (compreensões de lista) são uma maneira concisa e eficiente de criar listas em Python. Elas permitem que você gere uma nova lista aplicando uma expressão a cada item de uma sequência (como uma lista ou um intervalo) e, opcionalmente, filtrando os itens com uma condição.

**Exemplos**:

1. **Criando uma lista de quadrados**:
   Neste exemplo, vamos criar uma lista que contém os quadrados dos números de 0 a 9.

   ```python
   # Usando list comprehension para gerar quadrados
   squares = [x**2 for x in range(10)]
   print(squares)  # Saída: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
   ```

2. **Filtrando elementos**:
   Aqui, vamos criar uma lista que contém apenas os números pares de 0 a 9.

   ```python
   # Usando list comprehension com condição para filtrar números pares
   even_numbers = [x for x in range(10) if x % 2 == 0]
   print(even_numbers)  # Saída: [0, 2, 4, 6, 8]
   ```

3. **Transformando strings**:
   Vamos transformar uma lista de palavras em suas versões em maiúsculas.

   ```python
   # Usando list comprehension para converter palavras em maiúsculas
   words = ['python', 'java', 'c++']
   uppercase_words = [word.upper() for word in words]
   print(uppercase_words)  # Saída: ['PYTHON', 'JAVA', 'C++']
   ```

**Erros comuns**:
- Esquecer de usar colchetes `[]` ao criar uma list comprehension. Isso resultará em um gerador em vez de uma lista.
- Não usar a condição corretamente, o que pode levar a resultados inesperados.

**Melhores práticas**:
- Use list comprehensions para operações simples e legíveis. Para operações mais complexas, considere usar funções normais para manter a clareza do código.
- Sempre que possível, mantenha a lógica da list comprehension simples para facilitar a leitura e a manutenção do código.

## 4. Exception handling

> Pitfalls and best practices.

### 🧑 Como tratar exceções em Python?

Tratar exceções em Python é uma parte importante da programação, pois permite que você lide com erros de forma controlada e evite que seu programa falhe inesperadamente. O tratamento de exceções é feito usando as instruções `try`, `except`, `else` e `finally`.

##### Conceito
- **try**: bloco onde você coloca o código que pode gerar uma exceção.
- **except**: bloco que captura e trata a exceção se ela ocorrer.
- **else**: bloco opcional que executa se o código no bloco `try` não gerar exceções.
- **finally**: bloco opcional que sempre é executado, independentemente de uma exceção ter ocorrido ou não.

##### Exemplo
Aqui está um exemplo simples que demonstra como tratar exceções:

```python
def divide_numbers(num1, num2):
    try:
        # Tenta realizar a divisão
        result = num1 / num2
    except ZeroDivisionError:
        # Trata a exceção de divisão por zero
        return "Erro: Divisão por zero não é permitida."
    except TypeError:
        # Trata a exceção de tipos inválidos
        return "Erro: Ambos os valores devem ser números."
    else:
        # Este bloco é executado se não houver exceções
        return f"O resultado da divisão é: {result}"
    finally:
        # Este bloco é sempre executado
        print("Operação de divisão concluída.")

# Testando a função
print(divide_numbers(10, 2))  # Saída: O resultado da divisão é: 5.0
print(divide_numbers(10, 0))  # Saída: Erro: Divisão por zero não é permitida.
print(divide_numbers(10, 'a'))  # Saída: Erro: Ambos os valores devem ser números.
```

##### Armadilhas Comuns
- **Não capturar exceções específicas**: É uma boa prática capturar exceções específicas em vez de usar um `except` genérico, pois isso ajuda a identificar problemas mais facilmente.
- **Ignorar exceções**: Evitar o uso de `pass` em um bloco `except`, pois isso pode ocultar erros que você deve tratar.

##### Melhores Práticas
- Sempre que possível, capture exceções específicas.
- Use `finally` para liberar recursos, como arquivos abertos ou conexões de banco de dados.
- Considere o uso de `with` para gerenciar recursos, pois isso pode simplificar o tratamento de exceções.

## 5. Decorators

> Advanced topic explained step by step.

### 🧑 Explique o que são decorators.

**Conceito**: Decorators (ou decoradores) em Python são uma maneira de modificar ou estender o comportamento de funções ou métodos. Eles permitem que você "envolva" uma função com outra função, adicionando funcionalidades antes ou depois da execução da função original, sem alterar seu código.

Os decoradores são frequentemente usados para adicionar funcionalidades como logging, autenticação, verificação de permissões, entre outros.

**Exemplo**: Aqui está um exemplo simples de um decorador que imprime uma mensagem antes e depois da execução de uma função.

```python
def my_decorator(func):
    # Esta é a função decoradora
    def wrapper():
        print("Antes da execução da função.")
        func()  # Chama a função original
        print("Depois da execução da função.")
    return wrapper

@my_decorator  # Aplica o decorador à função
def say_hello():
    print("Olá!")

# Chama a função decorada
say_hello()
```

**Saída esperada**:
```
Antes da execução da função.
Olá!
Depois da execução da função.
```

**Erros comuns**:
- Esquecer de usar o `@decorator` antes da definição da função que você deseja decorar.
- Não retornar a função original corretamente no decorador, o que pode causar erros ou comportamentos inesperados.

**Melhores práticas**:
- Use o módulo `functools` para preservar a assinatura da função original ao criar decoradores. Isso pode ser feito usando `functools.wraps`.

Aqui está um exemplo atualizado que utiliza `functools.wraps`:

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)  # Preserva a assinatura da função original
    def wrapper(*args, **kwargs):
        print("Antes da execução da função.")
        result = func(*args, **kwargs)  # Chama a função original
        print("Depois da execução da função.")
        return result
    return wrapper

@my_decorator
def say_hello(name):
    print(f"Olá, {name}!")

# Chama a função decorada
say_hello("Maria")
```

**Saída esperada**:
```
Antes da execução da função.
Olá, Maria!
Depois da execução da função.
```

Os decoradores são uma ferramenta poderosa em Python e podem ser usados para uma variedade de propósitos, tornando seu código mais modular e reutilizável.
